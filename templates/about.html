PROJECT METHODOLOGY

How It Works

01

Text Input

The user enters or pastes a piece of text into the detection system.

02

Tokenization

The input text is converted into tokens that can be processed by the Transformer model.

03

RoBERTa Model

A fine-tuned RoBERTa Transformer analyzes patterns within the text.

04

Classification

The model predicts whether the input is likely human-written or AI-generated.

System Architecture

User Text → Tokenizer → RoBERTa → Classifier → AI / Human

Limitations

AI-generated text detectors are probabilistic systems. Their performance can vary depending on the language, topic, writing style and AI generator used to create the text.
